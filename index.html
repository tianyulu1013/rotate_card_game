📖 精灵翻翻阵 - 规则说明

🏆 1. 胜负判定

4×4 棋盘（共 16 格）。盘满或双方无牌可出时，控制卡牌数量多者获胜。

🗺️ 2. 落子与护盾

▪ 可以在棋盘任意空格落子。

▪ 全场第一张打出的卡牌自动获得【神圣护盾 】。

▪ 护盾只有 1 层，重复相生不会叠加层数。

▪ 护盾抵挡一次有效相克后破碎；该次攻击不会改变卡牌归属，也不会让卡牌旋转。

▪ 手机预判落子：点击第 1 下选定预览翻牌与加盾，再次点击同一格子确认落子。

⚔️ 3. 相克 (翻牌)

⚔️ 五行模式：木克土 → 土克水 → 水克火 → 火克金 → 金克木
🔢 数字模式 (大压小)：5克4 → 4克3 → 3克2 → 2克1 → 1克5

当你的接触边相克敌方接触边时，敌方卡牌旋转 180° 并转换为你的卡牌。

▪ 相克永远不会翻转己方阵营的牌。己方牌接触时只检查相生。

▪ 没有形成相克关系的敌我接触不会产生任何效果。

🌟 4. 相生 (授盾)

🌟 五行模式：木生火 → 火生土 → 土生金 → 金生水 → 水生木
🔢 数字模式 (隔位生)：1生3 → 3生5 → 5生2 → 2生4 → 4生1

主动落子与己方卡牌接触时，会检查接触边的两个方向；形成相生后，被生的一方获得【护盾 】。

▪ 相生只发生在同一阵营之间，不会给敌牌授盾。

▪ 每张牌最多持有 1 层护盾；已有护盾的牌不会继续叠盾。

💥 5. 连锁反应

刚被相克翻转的卡牌，会以新阵营身份继续检查相邻的敌方牌，形成相克时继续翻转。

▪ 默认规则下，连锁阶段只继续相克，不再触发相生或产生新护盾。

▪ 可在设置中开启【相生连锁 · 挑战自我】；开启后，连锁翻转的牌也会与己方牌触发相生护盾。

▪ 遇到己方牌时不会翻牌；遇到护盾敌牌时只击碎护盾，连锁不会穿过该牌。

▪ 关闭“连锁翻牌”后，只结算主动落子产生的第一层接触效果。

📋 6. 单条接触边判定顺序

① 先看阵营：己方接触只检查相生，敌方接触只检查相克。

② 再看护盾：有效相克优先击碎护盾；无盾才会翻牌并转换阵营。

③ 最后处理连锁：只有真正完成翻转的牌才成为下一层连锁来源。
